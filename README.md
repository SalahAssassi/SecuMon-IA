# SecuMon-IA

Plateforme de sécurisation de la monétique par intelligence artificielle.

Conception d'une plateforme de cybersécurité pour les échanges monétiques ISO 8583 :
protection du canal, détection d'intrusions et de fraudes par intelligence artificielle.

> Projet académique (PFA, EMSI). Données synthétiques et publiques uniquement.
